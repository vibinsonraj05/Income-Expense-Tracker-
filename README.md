# 💰 Income & Expense Tracker

A simple and interactive personal finance management web application designed to help users track income, monitor expenses, and manage their finances effectively. It provides a clear overview of financial transactions to support better budgeting and money management.

## ✨ Features

- Add income transactions
- Record daily expenses
- View transaction history
- Calculate total income
- Calculate total expenses
- Display available balance
- Track spending habits
- Simple and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/vibinsonraj05/Income-Expense-Tracker.git
```

### 2. Navigate to the project folder

```bash
cd Income-Expense-Tracker
```

### 3. Run the application

Open the main HTML file in your web browser.

Launch the application locally to explore the income and expense tracking features.
